# Getting help with a DTM mod

## First, the quick checks

- **The zip goes into the mods folder as it is**: `Documents/My Games/FarmingSimulator2025/mods`, not unzipped and
  not renamed. A renamed zip is a different mod to the game and to your savegame.
- **In multiplayer everyone needs the same version**, the server too. A different version stops you from joining.
- **Use the newest version**: the mod's **Latest** release on GitHub, or [dtmmods.com](https://dtmmods.com).
- **Look in the log**: `Documents/My Games/FarmingSimulator2025/log.txt`. Lines with `Error` or the mod's name
  usually say what went wrong. On a dedicated server, the server has its own log.

The [help page on dtmmods.com](https://dtmmods.com/help/) answers the common questions.

## Where to ask

| You have | Go to |
|----------|-------|
| A question, or you're not sure it's a bug | The [DTM Discord](https://discord.gg/2GTU9hAa3Q): PropaineX and Fennell answer there |
| A bug | **Issues** > **New issue** > **Bug report** in the mod's repository. Attach your `log.txt` and say which mod version you're on |
| An idea or a wish | [DTM Mods Ideas](https://github.com/orgs/DTM-Mods/discussions/categories/ideas), where everyone can vote |
| A translation, or a mistake in one | **Issues** > **New issue** > **Translation** in the mod's repository |
| A security problem (cheating, crashing a server, a leaked password) | Not a public issue: see [SECURITY.md](SECURITY.md) |

## AutoDrive, Courseplay and Better Contracts

Ours are forks of other teams' mods, with changes for our server. Report a problem with **our** version in our
repository. The original mods have their own teams and their own issue pages; please don't send them bugs from our
forks.
