# Security

Found a security problem in a DTM Mods mod or in our server setup, for example a way to cheat other
players' money in multiplayer, to crash a server on purpose, or a leaked password?

**Please don't open a public issue.** Tell us privately instead:

- send a direct message to **Fennell** or **PropaineX** on the [DTM Mods Discord](https://discord.gg/2GTU9hAa3Q)

Say which mod and version it is and how to reproduce it. We'll answer as soon as we can, fix it, and
credit you in the release notes if you like.

Ordinary bugs (something doesn't work, an error in the log) are welcome as public issues: use the
**Issues** tab of the mod's repository.
